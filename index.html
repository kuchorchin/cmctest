This file needs to know where your database lives.

Open index.html in any text editor and find the two lines near the top of the script that say PASTE_YOUR. Replace them with your project URL and publishable key from Supabase, under Settings → API. Save and reload.

The publishable key is meant to be public — it's in every visitor's browser by design. The database rules are what protect your data. Never paste the service role key here; that one bypasses every rule.
